# 依赖失效契约矩阵(DFR)

GreenPulse。开册 2026-07-29,零代码起步。

姊妹项目的 DFR 是**实测记录**(每格先执行故障、再记录观察到的行为);本项目还没有代码可以注入故障,所以本文件此刻是**契约**:每一格规定所需行为,并在实现该依赖的同一个 PR 里按 [R0.2](ENGINEERING_RULES.md) 红后绿落地为故障注入测试。**"Observed(实测)"列今天全部为空;它被填上实测行为之前,对应格子不算 PINNED,只算愿望。** 这套流程本身就是姊妹项目最有效的一份文档,形状原样继承。

## 铁律

> **调度器绝不基于编造的信号做"绿色"决策;绝不基于过期信号假装实时;绝不为了节能牺牲刚性任务 SLA。**

三条推论:

1. **编造有不止一扇门。** 调用合成生成器是显性的一扇;把缺失时段零填("这段时间碳强度为 0")、把过期预报当新预报、把平均口径标成边际,是同一行为的另外三扇。任何一扇都会把假绿证据写进对外材料。
2. **降级必须显式且可观测。** 信号断供时的正确行为是:**降级为 carbon-agnostic 模式 + 告警 + 决策记录标注 degraded**。降级不是失败;静默降级才是。
3. **分辨率与口径不是标签。** 曲线的实际**时间步距**(相邻时间戳间隔,下同)必须与其声明一致;15 分钟数据被按小时消费、average 被当 marginal 消费,都必须在边界处被拒绝。

**Class 分级**(与姊妹项目一致):CLEAR ERROR(报错并说清怎么办,目标态)/ CRASH-UNHELPFUL(库内部炸,能定位但不友好)/ **SILENT WRONG RESULT(不报错、继续算、产出貌似合理的数——最高危,本矩阵存在的理由)**。

## 矩阵

### DEP-1 — 碳/绿电信号 Provider(网络或文件)

| # | 失效模式 | 所需行为 | Class(若违约) | Observed(实测) |
|---|---|---|---|---|
| 1.1 | Provider 完全不可达 | 重试 N 次后:调度降级 carbon-agnostic + WARNING 告警 + 决策记录标 `degraded`;**绝不**用上次曲线冒充实时 | SILENT WRONG RESULT | — |
| 1.2 | 预报过期(取到的预报生成时间早于配置的最大时龄) | 拒绝该预报,同 1.1 降级;错误信息含预报时间戳与时龄阈值 | SILENT WRONG RESULT | — |
| 1.3 | 请求区间中段缺失 | 拒绝或显式掩码,错误信息命名缺失区间;**禁止零填/插值补齐后继续**(零碳强度=编造一段完美绿电) | SILENT WRONG RESULT | — |
| 1.4 | 返回值缺少口径标签(average/marginal)或单位异常(负值、量级离谱) | 边界处拒绝,命名字段与收到的值;无口径标签的碳强度在类型上不可构造(R1.5) | SILENT WRONG RESULT | — |
| 1.5 | 时间步距与声明分辨率不符 | 边界处校验实际步距,拒绝并同时报请求值与实测值 | SILENT WRONG RESULT | — |
| 1.6 | 重复时间戳 | 拒绝非唯一键,报重复数 | SILENT WRONG RESULT | — |
| 1.7 | 时区/夏令时歧义 | 边界处统一为 UTC;无时区信息的时间戳拒绝 | SILENT WRONG RESULT | — |

## 落地节奏

- 每个 DEP 分组随其实现 PR 落地为 `tests/test_fault_injection.py` 中的用例;所需行为已实现的用 PINNED(并做删守卫验证:临时删掉守卫,测试必须变红),尚未实现的用 **strict xfail** 挂账——这是唯一自带过期机制的豁免形状。
- 每个 Gate 评审时清点:PINNED 数 / xfail 数 / Observed 列空格数,三个数字进 Gate 记录。
- **最高优先落地顺序**(按"错误数字能走多远"排):DEP-4.4 前视泄漏 → DEP-1.1/1.2/1.3 信号编造三扇门 → DEP-5.1 静默放松约束 → DEP-8.2 假成功。
