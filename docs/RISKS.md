# GreenPulse 风险登记册与冻结政策

飞书「2026 AI 先锋未来人才大赛」世纪互联赛道。开册 2026-07-29。

配套 [`PLAN.md`](PLAN.md)(我们打算做什么)与 [`ENGINEERING_RULES.md`](ENGINEERING_RULES.md)(如何证明做到了)。本文件覆盖什么会打断我们,以及——更有用的——**到哪一天我们停止等待、按预案行动**。

**读法**(继承姊妹项目):P = 概率(L<25% / M 25-60% / H>60%);I = 影响(Fatal:交付物丢失或对外结果错误;Major:砍掉一个阶段;Minor:阶段内返工);**Trigger** = 把风险从"观察"升为"激活"的可观测事件;**止损日** = 无论风险是否解除、当天启用预案的日期——没有止损日的风险不叫被管理,叫等着被发现;Owner 用角色(PL 项目负责 / DL 数据 / ML 建模 / IL 基础设施)。复审节奏:每个 Gate,以及任何 Trigger 触发时。

## 2. 冻结政策

冻结存在的目的:让材料里的数字与代码产出的数字是同一个数字。

| 冻结 | 日期 | 范围 |
|---|---|---|
| **评测协议冻结** | **2026-08-05(Gate S)** | 基线集、指标集、口径、质量阈值与能效分级阈值(预注册)、负载与信号数据版本。**改一项 = 此前全部实验记录作废重跑** |
| **功能冻结** | **2026-08-14** | 代码、config;此后仅 fatal-defect |
| **材料冻结** | **2026-08-15** | README/路演脚本/演示物料及其中每个数字;08-16 提交 |

**冻结后可接受的变更(fatal-defect 判据,满足其一)**:① 修正对外材料中代码并不产出的数字;② 移除任何使收益不劳而获的通道(如调度器偷看未来信号——本项目版本的"泄漏");③ 修复文档化复现路径上的崩溃;④ 恢复硬不变量(SLA 保底、fail-closed 信号降级、口径标签、决策可重放);⑤ 许可/署名缺陷。

**明确不可接受**:调参、新特性、新基线、指标/阈值/协议更改、重构、超出改错范围的文档重写。理由(姊妹项目原文,逐字继承):冻结后改善数字的变更与拟合数字的变更,评审和我们自己都无法区分,所以一律禁止,包括善意的。

**审批**:提议人写明破坏什么/满足哪条判据/波及面/回滚;PL + 一名未写该变更的成员共同批准;自批无效。每个获批例外必须同时携带:红后绿证明、CHANGELOG 条目、全主线重跑记录、所有受影响数字在一切出现处同步更新——四者缺一,例外拒绝,缺陷改记为已声明的已知限制。
